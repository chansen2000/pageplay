## 实现要点（按 T7c 任务书契约逐字）

1. **`selector_from_chain(chain)`**（picker.py:230）：纯函数，链序 = 根在首、目标在尾。
   - 任一环有 id → 取**最靠近目标**的 id 环截断，该环渲染 `#id`，前面环节丢弃；
   - 无 id：`tag + 首个 class`，首环省 nth，其余环 nth>1 才带 `:nth-of-type(n)`（nth=1 冗余省略）——该规则逐字复现契约示例 `div.main > ul.list > li:nth-of-type(3) > a`；
   - 链长上限 5 环，超出截头（保靠近元素侧）；空链 ValueError。
2. **`COLLECT_CHAIN_JS`**（picker.py:34）：模块常量，收集 `window.__pageplay_locked` 到根的链，run_pick 与测试复用。
3. **`overlay_js()`**（picker.py:270，IIFE 本体 `_OVERLAY_JS` 在 picker.py:59）：hover 高亮（`closest("table,ul,ol,[role=grid]")` 优先，找不到用元素自身，固定定位 outline 覆层随 Box 移动）；↑ 扩选 parentElement / ↓ 栈收回；Esc 取消（真实 keydown 路径，暴露 `__pageplay_cancel` 入口）；点击锁定——表容器出列勾选条（表头文本 checkbox 默认全勾 + 确认），否则「下载此元素」「抓取此表」两按钮；确认 → `window.__pageplay_onconfirm({selector_hint, action, columns, rect})`；全程只 append `#__pageplay_overlay`，结束移除，不改业务 DOM。重复注入先清旧实例（单实例）。
4. **`run_pick(page, on_confirm)`**（picker.py:305）：`page.expose_function` 绑确认/取消 shim（固定 shim + `_ACTIVE` 路由，同页重复拾取正确）；等待期用 `page.wait_for_timeout(100)` 轮询（等待期间 playwright 派发绑定回调，sync API 单线程安全）；收到 payload → evaluate 收集链 → 生成 selector → 组装 `{"selector","action","columns","rect"}` → 返回前调 `on_confirm(结果)`；Esc / 窗口关闭 / 超时（600s 兜底）抛 `PickCancelled(RuntimeError)`；finally 清场（页面已关时忽略）。
5. **`cover_screenshot(page, selector, out)`**（picker.py:354）：先 `count()==0` 快速判未命中（不进 playwright 30s 超时），ValueError 带「重新框选」指引；再 `locator(selector).screenshot(path=...)`，返回 `Path(out)`。
