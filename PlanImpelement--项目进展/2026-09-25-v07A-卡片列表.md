# v0.7-A 卡片列表识别与提取（2026-09-25）

**背景**：sheng 真机发现淘宝订单列表是 div 卡片（同签名兄弟重复），v0.6.0 框选只认
语义表格（table/ul/ol/[role=grid]），卡片页收获步走不通。本任务给框选层加"重复
兄弟组"识别与字段勾选，run 侧加卡片提取执行器。

## 改动清单

| 文件 | 改动 |
|------|------|
| `pageplay/picker.py` | 覆层 JS：hover 候选优先级扩为 **语义容器 → 重复兄弟组 → 元素自身**。新增 `sameGroup`（同 tag+首个 class 且含非空文本的兄弟组，≥3 才成组）、`cardGroup`（自 hover 点向上取最大组，高亮组父容器）、`relFrom`/`pickFields`（首条记录内文本节点 → 字段候选：trim ≥2 字、相邻同文/同宿主去重，label 取前 8 字兜底"字段N"，rel=[{tag,nth}] 相对链 item 端在首）。锁定卡片组 → `renderFieldBar`（"识别到 N 条记录" + 字段勾选条，默认全勾）；`checkList` 为列勾选/字段勾选公共件。`confirmPick` payload 增 `list_mode`（缺省 "table"）/`fields`；`run_pick` 结果透传两键，selector 指向组父容器。↑↓ 扩收清 `curGroup`（重 hover 即恢复卡片模式） |
| `pageplay/actions.py` | 新增 `_CARDS_JS` + `extract_cards(page, list_selector, fields)`：容器内按同签名兄弟重算最大组（≥3）为记录，逐条按 field.rel 解析文本宿主取 trim 文本 → `[{"label": 值}, ...]`；rel 落空填 ""。fields 空 / 无记录组 → ValueError 人话 |
| `pageplay/runner.py` | 仅 table 分支一处：按 `step.get("list_mode")` 分派 extract_table（缺省）/ extract_cards（cards，传 `step["fields"]`）；detail 区分"抓表/抓卡片 N 行" |
| `pageplay/flows.py` | save_flow 校验兼容：kind=table 允许 `list_mode ∈ ("table","cards")`（缺省 table，旧 step 照收）；cards 必须带非空 fields，否则 ValueError |
| `tests/conftest.py` | 追加 `card_site` fixture（独占本次追加权）：GET /cards → 6 张同签名 div.card 卡片，每张订单号/标题/价格/状态四个文本节点（嵌套 div/span，非 table）；首卡标题 9 字用于验 label 截前 8 字 |
| `tests/test_picker_cards.py` | 新建 7 条：卡片 hover→锁定→确认全链路（真实合成 mousemove/click，不绕 JS）、语义容器优先级反面 guard（td 同签名成组但仍走表格路径）、runner 手写 cards step 整链 → CSV 6 行 2 列、flows 校验 4 分支 |
| `tests/test_actions.py` | 追加 3 条：extract_cards 6 行 × 2 字段、fields 空 ValueError、非列表容器 ValueError |
