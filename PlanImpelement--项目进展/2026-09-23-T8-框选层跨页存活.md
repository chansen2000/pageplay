# T8：框选层跨页存活（修 sheng 真机验收缺陷）

日期：2026-09-23
基线：git ef29bc9 v0.2.0（162 passed）
结果：全量 164 passed（162 基线 + 2 新增），零回归

## 缺陷与根因

现象：`pageplay pick` 后在弹出浏览器里点链接进入第二层页面，框选层（高亮/面板）
消失，无法继续框选。

根因（按五步定位，证据齐全）：
- 架构层：T7c 的注入机制是 `page.evaluate` 一次性注入，JS 生命周期 = 当前
  文档；跨页存活从一开始就没有归属机制（不靠参数能修）。
- 功能层：导航产生新文档 → 旧 JS 上下文销毁 → 覆层/监听全部消失；同时
  `_ensure_bindings` 用 `typeof window.__pageplay_onconfirm`（查当前文档）
  探测绑定，新文档探测为 undefined 会试图重复 `expose_function` 而抛
  already registered（Playwright 绑定本就随 page 跨文档持续有效）。
- 代码层：`picker.py` 旧 `_OVERLAY_JS` 无自愈、`run_pick` 只 evaluate、
  `_ensure_bindings` 探测维度错误。

## 修改内容（全部落在平台能力，无绕路）

### 1. pageplay/picker.py（371 → 426 行）

- `run_pick`：改 `page.add_init_script(overlay_js())`——每个新文档加载时
  自动布防；对当前已加载文档补一次 `evaluate`（同一份 JS，幂等；init
  script 不覆盖已加载页）。跨页后超时计时继续（deadline 一次性，不重置）。
- `_ensure_bindings`：删掉文档级 `typeof` 探测；`expose_function` 直接装，
  抛 already registered 则捕获复用既有 shim（回调经模块级 `_ACTIVE` 路由
  到最近一次会话，语义不变；非重复类错误如实上抛不吞）。
- `_OVERLAY_JS` 重构：
  - UI 三件套（overlay/box/panel）从 IIFE 顶层常量改为 `buildUi()` 按需建；
  - `alive()` 检测三件套是否仍挂在文档里；文档监听改 AbortController 统一
    布防/拆除（`arm()`/`disarm()`，`signal.aborted` 即监听失效）；
  - 心跳自愈：`setInterval(800ms)` 周期跑 `deploy()`（幂等：文档就绪才建
    UI，UI 在且监听在则不动）——覆盖 SPA 软跳转/同文档 DOM 重建剥掉覆层；
    文档就绪（DOMContentLoaded 或立即）先布防一次；
  - 确认/取消/清理路径置 `over` 标记并停心跳，杜绝结束后 UI 复活；
    `buildUi()` 重建时同步重置拾取态（locked/current/upStack）；
  - 确认 payload 增加 `url: location.href`——用户点确认那一刻的落点。
- `run_pick` 返回结构增加 `"url"` 字段：`payload.url`，缺省兜底 `page.url`；
  与 cli 记账用的 `page.url` 同文档取值一致（docstring 写明语义）。
- `PickCancelled` 语义不变：Esc / 关窗 / 600s 超时；跨页不重置。

### 测试基建的三个实证（探针钉出来的，不靠猜）

1. `set_content` 全新页 = about:blank origin，`pushState` 换路径抛
   SecurityError；先 goto 真 origin 再 set_content 则 origin 保留、
   pushState 正常且 `page.url` 同步更新。
2. `expose_function` 重复注册抛 `Error: Function ... has been already
   registered`（捕获匹配 "already"）。
3. `add_init_script` 传纯字符串只按脚本源码解析、**不自动调用**：测试
   确认脚本顶层 `return` 曾造成 SyntaxError 整段没跑（探针见所有条件为真
   但 interval 从不触发）；必须 IIFE。`page.evaluate` 传函数串则会自动调用。
