## 为什么改

sheng 真机 8 标签页实测：grab 注入落在空白新标签页上，红框人看不到。根因是 `cli_grab.py` 取页用位置假设 `pages[-1]`（"最近打开 = 用户正在看"），多标签场景下最后一个完全可能是空白新标签页（chrome://new-tab-page / about:blank）。

## 改了什么

### 1. 新建 pageplay/target_page.py（69 行，目标页判定独立成模块）

- session.py 正好 500 行顶格（红线 #26），目标页函数按任务书倾向放独立文件，给 session 减负。
- `BLANK_PREFIXES`（:24）= `("chrome://", "about:", "devtools://")`。
- `is_blank(page)`（:27）：URL 以空白前缀开头或为空 → 空白页（chrome://new-tab-page 属空白）。
- `page_visibility(page)`（:33）：`page.evaluate("document.visibilityState")`，异常（页已被关等）→ `"hidden"`；此函数是测试 monkeypatch 注入点。
- `pick_target_page(context)`（:45）四级判定：剔空白页 → `visibilityState == "visible"`（人正看着的前台标签）取最后一个 → 全 hidden 回落非空白页最后一个 → 只有空白页/一页都没有 → 人话 `RuntimeError("浏览器里没有可用的标签页：先打开窗口并浏览到目标页")`（:55）。多可见页 log.info 说明取最后一个（:59），选中页 log.info title/url 前 60 字（:68）。只读不动页：不导航、不关页、不改焦点。

### 2. cli_grab.py 接线（3 处）

- :4 docstring 更新（"取 pages 最后一个"→ pick_target_page 可观测判定）。
- :28 `from .target_page import pick_target_page`。
- :59-67 原注释块（手写 pages 判空 + `pages[-1]`）替换为 `try: page = pick_target_page(context) except RuntimeError: print(stderr); return 1`（:62-66）——退出码语义不变（零页=1），人话文案含既有测试锚点"先打开窗口"。

### 3. pick 未改（任务书"两处"与代码实况不符，如实上报）

任务书写"pages[-1] 取页处替换（grab、pick 两处）"。实读代码：`cli_pick.py` 全文**没有** pages[-1]；`_cmd_pick` 取页处是 `context.new_page()`（cli_pick.py:241）——开自己的新页再导航，与被任务书明确豁免的 record（cli_pick.py:296）完全同模式。且 pick 冷启动（守护零标签页）必须能开新页工作，换 pick_target_page 会在零页时抛 RuntimeError 废掉 `pageplay pick <站点>` 主流程，会话结束的 `page.close()`（cli_pick.py:264）还会关到人自己的标签页。这是产品语义变更（sheng 拍板项），本任务不自行扩大；pick 的新开页天然是前台标签，不存在"注入进看不见的页"的病。**若 sheng 要 pick 也改附着可见页，另行立任务。**

### 4. 契约内部矛盾的一处定案

任务书函数契约第 4 条"全空 → context.pages 最后一个"与测试契约"只有空白页 → RuntimeError 人话"互斥。按测试契约 + 报错文案（"没有可**用**的标签页"）定案：**只有空白页 = 没有可用标签页，报人话，不兜底返回空白页**——向空白页注入红框正是 T19 要修的病，兜底等于把病根留作 fallback；与既有 grab 零页人话口径一致。

### 5. 测试（tests/test_target_page.py 新建 236 行，14 个，真 chromium）

- 真 chromium 直启（playwright `chromium.launch(headless=True)`，模块级夹具；不走 CDP 守护），内容页用 `flow_site`（/start /list /other），空白页先试 chrome://new-tab-page、打不开保持 about:blank（两者都落空白前缀）。
- 覆盖：is_blank 前缀/空 URL 纯判定（4 参数化）；page_visibility 异常→hidden；三页场景 headless 全 visible 跳空白选最后内容页（**sheng 真机等价小场景**）；中间页 visible 压过位置选中间；仅首页 visible 压过 pages[-1]；全 hidden 回落非空白最后者；多可见页取最后一个且 caplog 断言"最后一个"+页 url 进日志；**8 页镜像真机场景**（7 内容页+末尾空白 → 选第 7 内容页）；只有空白页/零页 → 人话 RuntimeError。
- 既有 test_grab 7 个用例零改动全绿（替身页无 evaluate → 走 hidden 回落分支，行为兼容）。
