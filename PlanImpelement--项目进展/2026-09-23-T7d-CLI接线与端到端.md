## 实现要点

1. **接线原则**：处理逻辑全部已在 picker/actions/recipes 模块，cli 只做编排——
   `_cmd_pick`（cli.py:354）解析同 doctor（`_resolve_target` 已存优先）→
   `session.open().new_page()` → goto 生效 URL（贴的 URL 优先，否则站点
   home_url）→ `picker.run_pick(page, _print_locked)` → 组装 recipe（url 记
   实际落点 `page.url`，`columns` download 为 None，带 version/screenshot）→
   `recipes.save_recipe` → `picker.cover_screenshot` 落
   `recipes/<名>.png` → 打印 `pageplay run <名>` 指引 → 0；`PickCancelled` →
   "已取消" → 1；`finally: session.close()` 必关浏览器。默认名
   `<站点>-<已有 recipe 数+1>`（cli.py:369）。
2. **`_cmd_run`**（cli.py:384）：recipe 名跨站找（`_recipe_site_dirs()` 遍历
   sites 根下有 recipes/ 的站，cli.py:346）；找不到 → stderr 列出现有全部
   recipe 名 → 1。站点预设按 recipe["site"] 走 `_resolve_target`（已存 →
   内置 → KeyError 带 login 指引）。`session.open(headless=not --show)` →
   goto recipe.url → `actions.check_page_risk(page.content())`（RiskTriggered
   由 main 映射 2）→ `wait_for_selector(timeout=15000)` 超时 → "页面结构可能
   变了，请重新 pick <站>" → 1（PlaywrightTimeoutError 精确捕获，cli.py:36
   导入别名）→ table 走 `extract_table + save_table`（stem 带时间戳
   `%Y%m%d-%H%M%S`）、download 走 `download_element` → 产物打绝对路径 → 0。
   out_dir 缺省 `~/Downloads/pageplay/<recipe名>`。
3. **`_cmd_recipes`**（cli.py:437）：无参遍历全部站，带参经
   `_resolve_site_or_report` 只列该站；输出 名字/动作/URL/创建时间；空态给
   pick 指引 → 0。
4. **session.open 加宽**（session.py:231-243）：`headless: bool = False`
   关键字透传 `_start_context`，默认 False 行为不变（docstring 同步）。
5. **测试替身**（test_cli.py）：`StubSession.open` 加 `headless` 形参并记录
   （追加式，既有行为不变）；`PickPage`/`RunPage`/`DownloadPage`/
   `OnePageContext` 按 playwright 调用形状模拟（eval_on_selector 返回读表
   原始 dict 走真 `extract_table`，expect_download 模拟 contextmanager 形状
   走真 `download_element`）；recipe 手写经真实 `save_recipe` 落盘。
