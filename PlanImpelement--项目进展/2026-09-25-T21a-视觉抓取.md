# T21a：视觉抓取第二路——截屏把屏幕看到的表格转成表格（2026-09-25）

## 业务结果

DOM 框选（grab/pick）之外的第二条取数路：页面用 canvas 渲染、图片表格、
影子 DOM 等结构读不出的场景，把「人正看着的那页」整页截图交给 bigmodel
视觉模型（glm-4v-plus），识别出表格转成行 [{"列": "值"}]，照旧落
CSV+JSON + 落账 runs.jsonl。复用 T19 可见页判定与 save_table 落盘层，
CLI 是唯一真相源，GUI 只是加一个按钮。

## 为什么这么改

- 视觉引擎与命令分两文件：vision.py 不依赖 playwright 之外任何会话状
  态（page 参数即 duck-type），纯引擎好测；cli_vision.py 只做附着/选页/
  落盘落账编排，与 cli_grab 同构，不引入新模式。
- `_post` 抽出来是测试收敛点：urllib 只此一处，测试要么桩掉它（测
  payload 组装），要么把 ENDPOINT 指到本地假服务（测真实 HTTP 路径），
  两条路都不出外网。
- key 只进 Authorization 头：错误消息、账本、日志全不落 key，脱敏在
  错误构造处一次做对，不留"忘了脱"的分支。
