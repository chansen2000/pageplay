# v0.10 第 2 版：列表抓取真机可用（2026-09-27）

状态：**sheng 真机验收「基本可以用了」**。未 commit。测试与 GUI 两块未收口（见「未完成」）。

## 业务结果

淘宝「已买到的宝贝」页：点一下订单列表 → 锁定整页 30 单 → 一件商品一行（37 行，订单级字段每行重复）→ 列名以中文为主、按钮列默认不勾 → 确认落 CSV/JSON。选错可 Esc 重选、点别处换选、↑↓/面板换层；改过的列名按站记住。

## 实现链路

```
hover/点击 → __pp_groups(el)          收集全部候选层，默认记录数最多的一层（排除 body/html）
          → __pp_scan(group)          记录 → 子项(itemInfo) → 可见文本叶子 → 碎片合并 → 跨记录统计列(≥50%)
                                      列名：记住的名字 → 紧挨标签 → 值前缀 → 词典 → 列N；按钮/全同值默认不勾
          → 面板（_overlay_panel_js） 重选/退出/换层条/列勾选/改名/预览/只抓链接
          → confirm payload(list_mode=list, record_selector, sub_sem, columns)
          → listscan.extract / __pp_extract   与 scan 同一条 fieldsOf 管线
          → actions.save_table          CSV+JSON；改名写 ~/.pageplay/sites/<站>/colnames.json
```

## 关键修复与根因

| 问题 | 根因 | 修法 |
|---|---|---|
| 旧 cards 列名是数据、错位、丢列 | 字段 = 首条记录第 k 个文本节点；推荐区嵌在首单 DOM 内 | 跨全部记录按 sem 路径统计，<50% 出局（推荐区 1/30） |
| 价格拆成 650 / 00 两列 | ￥/650/./00 是 4 个 span | 同行（垂直重叠 ≥50%）且水平间距 ≤3px 的碎片合并 |
| 选择器随淘宝发版失效 | 写死 `xxx--哈希` class | `[class*="语义名--"]` |
| 锁成「3 条记录」 | scanGroup 取最近一层；每单内部嵌同名 trade-container | 收集全部候选层，默认记录数最多 |
| 重选要退出整个框选 | Esc = cancelPick；锁定后点击 return | 锁定态 Esc = 解锁重选；点别处直接换选；「退出」才结束 |
